# ウマ娘 プリティーダービー 育成サポートツール

最新育成シナリオ「**らっしゃい！トレセン軒！ ～恩返し、始めました～**」に対応した、最適サポートカード編成＆時期別地域選択ガイドツールです。

---

## 🌟 主な機能

1. **距離別 最適サポートカード編成ビューアー**
   - 短距離・マイル・中距離・長距離・ダートの5区分に対応
   - Tier 1（最適構成）、Tier 2（準最適）、無課金・微課金向け（Budget）の3パターンを網羅
   - 目標ステータス目安（スピ1800/スタ1450等）と推奨継承因子（スタ18、パワ12等）の提示
   - シナリオ必須枠（SSR 駿川たづな・新）および各種代用カードの候補リスト

2. **時期（ジュニア・クラシック・シニア）× 距離別 地域選択ガイド**
   - 友情練習時の「235調整」（基礎獲得量2・3・5の組み合わせによる毎ターン確定コツ獲得）を完全フォロー
   - 各時期（ジュニア・クラシック・シニア）ごとの距離別推奨地域（函館・東京・阪神・札幌・京都）
   - 各時期の優先ステータスと立ち回り・アクションプラン解説

3. **Web & YouTube 検証情報集約**
   - 検証系YouTuber、note検証勢、大手攻略サイト（Game8等）の最新検証結果と定石理由を集約

4. **PC・スマホ両対応（レスポンシブデザイン）**
   - スマートフォン縦画面での片手操作に最適化されたタブ・カードUI
   - ダークモード / ライトモードのワンタップ切り替え（設定はローカル保存）
   - 外部サーバー不要（ローカルブラウザでダブルクリックするだけで即動作）

---

## 🚀 使い方

### 1. ブラウザで直接開く（最も簡単）
`index.html` をダブルクリックして Google Chrome, Microsoft Edge, Safari 等のブラウザで開いてください。
インターネット接続がなくても完全オフラインで高速動作します。

### 2. スマートフォンで閲覧する場合
- PCと同一Wi-Fi環境下でローカルサーバー（`npx serve` や Pythonの `python -m http.server`）を起動し、スマホのブラウザからIPアドレスを入力してアクセス
- または GitHub Pages / Vercel / Netlify 等に本リポジトリをアップロードすることで、スマートフォンからいつでも手軽にブックマーク・ホーム画面追加（Webクリップ）して利用可能です。

---

## 📁 ファイル構成

- `index.html` : アプリ本体（レスポンシブHTML/CSS/JS）
- `data.js` : 攻略・編成・地域・動画ナレッジのデータファイル（ブラウザ直開き対応）
- `uma_meta_data.json` : 外部連携・データ更新用の生JSONデータ
