## 🌟 主な機能

### 1. 手持ちサポカ逆引き・現実的デッキビルダー（My Box Deck Builder）
- 所持カード（全64枚・10月最新サポカ対応）の凸数（未所持 / 無凸 / 1凸 / 2凸 / 3凸 / 完凸）を登録・自動保存（`localStorage`）
- 全20パターン（5距離 × 4脚質）の「自前5枠 ＋ 最適レンタル1枠（完凸）」の現実的最高戦力デッキを自動算出
- **同名キャラ重複禁止ルール（例：ミホノブルボンやメジロマックイーンの複数編成不可）を100%厳守**
- 不足枠・手持ち状況に応じた**戦略的レンタル推薦理由（診断）**を自動生成（たづな無凸所持時はフォーエバーヤングやマチカネタンホイザ完凸をレンタル等）
- 有力な入れ替えサブ・ベンチ候補の提示機能
- ワンタップのクイックプリセット（配布・SR完凸、主要SSR低凸＋SR完凸、全カード完凸、リセット）

### 2. 定期自動更新パイプライン ＆ オンライン即時同期機能 【NEW】
- **GitHub Actions 自動定期実行 (`.github/workflows/auto_update_meta.yml`)**:
  - 毎日12:30 JST（ガチャ更新30分後）および21:30 JSTに自動実行。
  - 新規サポカ・新PvPイベントの差分を検知し、メタデータ更新・全テスト実行・自動プッシュを完全無人化。
- **Webアプリ内「🔄 オンライン同期」ボタン**:
  - アプリ画面右上のボタンをタップするだけで、GitHub上の最新データを即時取得・画面再描画。
- **ワンコマンド同期パイプライン (`npm run sync-meta`)**:
  - ローカルやCI環境で即座にデータ同期と整合性テストを実行可能。

## 🚀 使い方

### 1. ブラウザで直接開く（最も簡単）
`index.html` をダブルクリックして Google Chrome, Microsoft Edge, Safari 等のブラウザで開いてください。
インターネット接続がなくても完全オフラインで高速動作します。

### 2. スマートフォンで閲覧する場合
- PCと同一Wi-Fi環境下でローカルサーバー（`npx serve` や Pythonの `python -m http.server`）を起動し、スマホのブラウザからIPアドレスを入力してアクセス
- または GitHub Pages に本リポジトリをアップロードすることで、スマートフォンからいつでも手軽にブックマーク・ホーム画面追加（Webクリップ）して利用可能です。

### 3. 最新データの同期・検証コマンド
```bash
# 自動テスト（DOM描画・全20編成キャラ重複ゼロ・総計10法則）
npm test

# メタデータの自動同期パイプライン実行
npm run sync-meta
```

## 📁 ファイル構成

- `.github/workflows/auto_update_meta.yml` : 定期自動更新 GitHub Actions
- `scripts/sync_meta_pipeline.js` : メタデータ自動更新・同期パイプライン
- `scripts/test_all.js` : 総合自動テストスイート
- `package.json` : プロジェクト構成・CIスクリプト定義
- `index.html` : アプリ本体（レスポンシブHTML/CSS/JS ＆ オンライン同期機能）
- `data.js` : 攻略・編成・地域・ナレッジデータファイル（ブラウザ直開き対応）
- `uma_meta_data.json` : 外部連携・データ更新用の生JSONデータ
